# Simple Interest Calculator

This project calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate in percentage.
- **Time:** The time period in years.

## Usage

1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Calculate the simple interest using the formula above.

## Example

- Principal: 1000
- Rate: 5%
- Time: 2 years
- Simple Interest: 100
